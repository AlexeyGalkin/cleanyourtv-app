## Как это работает

| 1. Подключить | 2. Проанализировать | 3. Очистить |
| :-: | :-: | :-: |
| <img src="docs/images/phone-connect.png" width="220" alt="Телевизор спрашивает, доверять ли телефону"> | <img src="docs/images/phone-what-we-found.png" width="220" alt="Найдено 22 пункта для отключения"> | <img src="docs/images/phone-done.png" width="220" alt="Телевизор готов"> |
| Приложение находит телевизор в сети Wi-Fi и показывает, как пустить телефон с помощью пульта. | Оно читает, что есть на телевизоре, и показывает план: что отключится, а что останется. Пока ничего не меняется. | Нажмите «Очистить». Сначала создаётся точка восстановления, потом лишнее отключается и включается новый главный экран. |

**Нужен** Android-телефон (Android 9 или новее, с блокировкой экрана) в той же сети Wi-Fi, что и
телевизор. Скачайте APK и откройте его, чтобы установить. Подключение занимает около минуты (вы
включаете отладку по сети с пульта, приложение показывает как), а вся очистка около пяти минут.

Возвращайтесь в любой момент: включить приложение обратно, проверить остатки после обновления
телевизора, поменять панель приложений или оформление, или отменить всё.

## Что получит ваш телевизор

Новый главный экран пока получают не все телевизоры. Приложение говорит, что достанется вашему
телевизору и почему, ещё до любых изменений, на экране «Мы нашли».

| | Какие телевизоры | Что делает приложение |
| :- | :- | :- |
| **Новый главный экран и очистка** | Телевизоры, на которых тестировщики подтвердили, что смена главного экрана сохраняется после перезагрузки: большинство Xiaomi и Redmi на Android 9–11, ряд моделей OnePlus, Sony, Hisense, Homatics, MECOOL, Strong, Toshiba, SHARP, JVC, Philips, realme, Kodak и другие, чей список это разрешает | Отключает мусор и делает главным экран Clean Your TV, предварительно создав точку восстановления |
| **Пока только очистка** | Большинство Google TV (их мастер настройки держит Wi-Fi или для модели ещё нет списка), незнакомые приложению модели, Chromecast и TV Streamer от Google (смена экрана стоила бы трансляции) | Отключает рекламу, слежку и фоновые приложения. Родной главный экран остаётся, поэтому реклама, которую рисует он сам, тоже остаётся |
| **Невозможно** | Fire TV, китайские прошивки TCL, Android 7 и старше | Только очистка, и приложение говорит об этом сразу |

[Список телевизоров](https://udhaykumarbala.github.io/cleanyourtv-app/tvs/) показывает, что получает
каждая модель сегодня. Модель без собственного списка продвигается, когда владельцы присылают её отчёт
из приложения («Помочь добавить этот телевизор»).

## Два способа почистить телевизор

[Clean Your TV](https://github.com/Gathin23/cleanyourtv) даёт любому Android TV спокойный главный экран
без рекламы и отключает мусор по спискам, проверенным сообществом. Сам по себе он требует компьютера:
вы запускаете его скрипты или отдаёте его промпт ИИ-агенту. Это приложение делает всё с телефона.

| | Репозиторий Clean Your TV | **Приложение Clean Your TV** (этот репозиторий) |
| :- | :- | :- |
| **Нужно** | Компьютер с ADB или ИИ-агент вроде Claude Code | **Только Android-телефон** в той же сети Wi-Fi |
| **Вы делаете** | Запускаете скрипты или даёте промпт агенту | **Нажимаете «Начать», проверяете план, нажимаете «Очистить»** |
| **Для кого** | Энтузиасты, темы и новые списки телевизоров | **Для всех**: для вас, ваших родителей и друзей |

Оба способа дают один и тот же главный экран Clean Your TV и одни и те же списки сообщества, отключают
приложения без удаления и сохраняют путь назад для каждого изменения.

## Безопасность с самого начала

- **Вы видите каждый шаг.** Ничего не запускается, пока вы не посмотрели план, а экран «Выбор»
  показывает каждую команду, которую отправит приложение, по порядку.
- **Ничего не удаляется.** Приложения отключаются для основного пользователя, поэтому каждое можно
  вернуть. Wi-Fi, Play Маркет, пульт, источники и всё, что нужно Android, защищены и никогда не
  трогаются; специальные возможности, трансляция, голос и обновления отключаются, только если вы так решите.
- **Отменить можно что угодно.** Вернуть одно приложение или всё из точки восстановления. «Сохранить
  копию» выгружает простые скрипты восстановления, которые работают с любого компьютера с adb, даже
  без этого приложения.
- **Сторож на телевизоре.** Если телефон не подтвердит новый главный экран за 150 секунд (пропал Wi-Fi,
  сел телефон), телевизор сам вернёт свой главный экран.
- **Осторожность там, где нужно.** На телевизорах, где смена главного экрана вызывает проблемы,
  приложение делает только очистку и объясняет почему.
- **Приватность.** Без аккаунтов, аналитики и рекламы. Приложение общается с вашим телевизором и, только
  когда вы просите, с GitHub ради обновлений. В форке ещё с поиском городов Open-Meteo, когда вы ищете
  город для погоды. Отладка по сети в конце снова выключается, если вы не решите её оставить.

## Для разработчиков

```bash
git clone --recurse-submodules https://github.com/AlexeyGalkin/cleanyourtv-app.git
cd cleanyourtv-app
./gradlew check assembleDebug        # JDK 21 и Android SDK
```

Приложение на Kotlin и Jetpack Compose, которое само говорит с телевизором по ADB, без компьютера
посередине. [CONTRIBUTING.md](CONTRIBUTING.md) (на английском) описывает тесты, эталонные скриншоты,
правила модулей и сборку выпусков.

### Сборка форка

- **В GitHub Actions** (ничего ставить не нужно): workflow `fork-apk` собирает ТВ-надстройки, встраивает
  их и собирает подписанный APK. Ему нужны два секрета репозитория: `CYT_KEYSTORE_B64` (хранилище ключей
  PKCS12 в base64) и `CYT_KEYSTORE_PASSWORD`. Переменная репозитория `CYT_SIGNER_SHA256` не даст подписать
  чужим ключом. Запустите его вручную, чтобы получить тестовый APK (артефакт), или отправьте тег `vX.Y.Z`,
  равный `versionName` в `app/build.gradle.kts`, чтобы получить релиз GitHub с APK.
- **Локально:** JDK 21 и Android SDK (платформы 34 и 37). Сначала `scripts/fork/bundle-addons.sh`
  (с `CYT_ADDON_KEYSTORE` и `CYT_ADDON_KEYSTORE_PASSWORD` или `_FILE`), потом
  `./gradlew :app:assembleFullRelease` (с `CYT_RELEASE_KEYSTORE` и `CYT_RELEASE_KEYSTORE_PASSWORD`).
- **Перевод:** `python3 scripts/fork/check-translations.py . ru` сверяет каждый файл `values-ru` с английским
  (ключи, плюралы ICU, подстановки). Термины собраны в [scripts/fork/GLOSSARY-ru.md](scripts/fork/GLOSSARY-ru.md).
- **Обновление из оригинала:** каждый понедельник workflow `upstream-sync` пробует влить изменения автора
  (`udhaykumarbala/cleanyourtv-app`, ветка `main`) и открывает PR или issue со списком конфликтов. Вручную:
  `git fetch upstream && git merge upstream/main`. Если обновился лаунчер (`third_party/cleanyourtv`), запустите
  `scripts/fork/build-tv-apks.sh`: он наложит панель виджетов на новый лаунчер, соберёт, подпишет и обновит пины.
